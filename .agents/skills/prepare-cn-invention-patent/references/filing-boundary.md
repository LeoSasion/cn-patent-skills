# CNIPA 申请与电子提交边界

## 当前核验状态

本文件中的链接和规则最后核验于 **2026-09-01**。正式提交前必须再次打开国家知识产权局官方页面，确认法律规则、表格、文件编码、数据标准、转换工具和系统要求仍然有效。

## 发明专利申请文件

国家知识产权局公开指引列出的主要文件包括：

- 发明专利请求书；
- 说明书摘要，必要时包括摘要附图；
- 权利要求书；
- 说明书；
- 必要时提交说明书附图。

请求书中的申请人、发明人、地址、联系人、优先权等字段必须由用户或专业代理人员确认。不能从技术材料、参考专利、公司名称或管理关系推断。

## 当前电子申请要求

国家知识产权局通知明确：自 2026 年 1 月 1 日起，以电子形式办理专利申请及相关手续，应提交符合要求的 XML 格式专利电子文件，不再接受非 XML 格式的专利电子文件。

通知附件列出的发明申请文件上传类别包括：

- `100001` 权利要求书；
- `100002` 说明书；
- `100003` 说明书附图；
- `100004` 说明书摘要。

其它表格类 XML 按专利业务办理系统当期要求填写。数据标准、转换工具、操作手册和系统校验规则可能更新，不能把旧模式文件或本地推测当作当前规范。

## 本 Skill 的能力边界

本 Skill 可以：

- 生成和审计规范申请文本；
- 生成明确标注的申请前校对 PDF；
- 整理待转换的申请源、附图、身份缺口和文件编码清单；
- 在官方转换工具和当期规范可用时，协助核对转换前后内容。

本 Skill 不能仅凭 Markdown、DOCX 或普通 PDF 宣称已经生成可提交 XML。缺少当前官方数据标准、官方或被认可的转换工具、系统校验和真实回执时，状态只能写为“XML 提交准备”，不能写为“XML 已验证”或“可直接提交”。

不要自造 XML 命名空间、元素、校验结果或回执；不要把 PDF 改扩展名或嵌入 PDF 后称为 XML 申请包。

## 申请前校对 PDF

- 只用于申请人、发明人和专业代理人员审阅。
- 首页必须写明：`申请前校对稿（非电子提交格式）`。
- 不显示未确认的申请号、申请日、公开号、分类号、代理机构、代理师、审查员或授权状态。
- `CN...A` 和 `CN...B` 是公开文献标识，不是申请人电子提交模板。
- 不从公开专利复制技术内容、权利要求、附图、身份或官方元数据。
